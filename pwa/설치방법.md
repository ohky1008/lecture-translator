# 아이패드 · 맥 · 윈도우에 설치하기

이 폴더(`pwa/`)를 HTTPS 주소로 올리면 앱처럼 설치됩니다.
마이크 녹음과 음성 인식은 브라우저 보안 정책상 **HTTPS에서만** 동작합니다(파일을 직접 열면 마이크가 막힙니다).

## 1. 올리기 — GitHub Pages (연결된 저장소: `ohky1008/lecture-translator`)

1. `pwa/` 폴더 안의 파일 전체를 저장소 루트(또는 `docs/` 폴더)에 올립니다.
2. 저장소 Settings → Pages → Source: `main` 브랜치 / 루트(또는 `/docs`) 선택 → Save.
3. 1~2분 후 `https://ohky1008.github.io/lecture-translator/` 주소가 열립니다.

Netlify에 `pwa` 폴더를 드래그해서 올려도 똑같이 됩니다.

## 2. 설치하기

**아이패드 (Safari)**
주소 열기 → 공유 버튼 → "홈 화면에 추가" → 홈 화면 아이콘으로 전체화면 실행

**맥 (Safari 17+)**
주소 열기 → 공유 버튼 → "Dock에 추가"

**맥 · 윈도우 (Chrome / Edge)**
주소창 오른쪽 설치 아이콘 클릭 → "설치"

## 3. 첫 실행 시

설정에서 두 가지를 넣어주세요.

1. **음성 인식** → OpenAI Whisper 선택 + OpenAI API 키 입력
   - 모델: `whisper-1`(기본), `gpt-4o-transcribe`(더 정확), `gpt-4o-mini-transcribe`(빠름)
2. **번역 엔진** → Claude 또는 GPT 선택 + 해당 API 키 입력
   - GPT를 고르면 음성 인식 키를 따로 넣지 않아도 같은 키를 씁니다.

키와 설정은 기기 안에만 저장되고, 앱을 다시 열어도 유지됩니다.

## 4. 녹음 파일 저장 위치

녹음은 앱이 기기 안(브라우저 저장 영역)에 자동 보관하므로, 앱을 닫았다 열어도 문장·문단 다시듣기가 됩니다. 남은 용량은 설정 → 녹음 저장에서 확인할 수 있습니다.

파일로 꺼내려면 강의 상세 화면의 **녹음 내보내기**를 누르세요.

- 맥 · 윈도우 (Chrome/Edge): 설정 → 녹음 저장 → "저장 폴더 지정"으로 폴더를 한 번 정해두면 이후 그 폴더에 바로 저장됩니다.
- 맥 Safari: 누를 때마다 저장 위치를 묻거나 다운로드 폴더에 저장됩니다.
- 아이패드: "파일" 앱에서 저장 위치를 고를 수 있고, 기본값은 다운로드 폴더입니다.

## 참고

- 설치 후에는 오프라인에서도 화면이 열립니다. 단 음성 인식과 번역은 인터넷이 필요합니다.
- 음성 인식을 OpenAI Whisper로 쓰면 아이패드·맥·윈도우 어디서든 동작합니다(브라우저 내장 인식은 크롬·엣지 전용).
- 앱을 수정하면 `pwa/` 폴더를 다시 올리고, `sw.js`의 `CACHE` 버전 번호를 올려주세요(`v2` → `v3`).
